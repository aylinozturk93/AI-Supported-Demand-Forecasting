# 🎯 Project Objectives

- Compare forecasted demand with actual demand
- Detect abnormal forecast deviations
- Improve forecasting accuracy
- Support logistics planning decisions
- Demonstrate a rule-based anomaly detection approach using Python

---

# 🔍 Forecasting Logic

The Python application evaluates forecast quality using multiple indicators, including:

- Forecast Error
- Error Rate
- Risk Score
- Risk Level
- Anomaly Detection
- Risk Reason
- Adjusted Forecast Recommendation

The final output classifies each record based on forecasting performance and provides recommendations for further analysis.
